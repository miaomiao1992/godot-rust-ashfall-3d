# ASHFALL · 余烬禁区 v0.2.1

Godot 4.7 + Rust 核心的 3D 第一人称末日生存射击游戏。

## Windows64 游玩

下载 `ASHFALL-Windows64-v0.2.1.zip`，完整解压后双击 `ASHFALL.exe`。
无需安装 Godot 或 Rust。系统要求：Windows 10 / 11 64 位、支持 OpenGL 3.3 的显卡。

## 内容

- 三个空间结构完全不同的关卡：断桥高架、沉没船坞、熔心实验场。
- 九波尸潮、普通感染者与疾行者、三类精英、三个带阶段技能的 Boss。
- 下载的 CC0 带皮肤／血污贴图与骨骼动作的丧尸模型。
- 击杀成长、五种等级解锁武器、跨关强化、死亡重开与个人纪录。
- 固定三连／环形／十字腐蚀图案，至少 1.6 秒预警、数量限制及防叠加。

## 本版修复

- 修复第三关怪物被击退出圆形地板后仍占据存活数量、导致无法进入第二波的问题。
- 气闸后方增加实体封挡；意外跌落怪物保留血量回到可达地面。
- 出生位置检查实际碰撞和可达路径，失败配额保留并重试。
- 存活计数与真实活怪同步，Boss 待生成状态有独立保障。
- 修复快速删除怪物时的材质失效报错。

第三关每波还需要累计关闭 1／2／3 个冷却阀：靠近控制台按 **E**。

## 操作

WASD 移动，鼠标转向，左键射击，右键瞄准，Shift 冲刺，空格跳跃，R 换弹，F 手电，1–5／滚轮切换武器，E 操作，Esc 暂停。
