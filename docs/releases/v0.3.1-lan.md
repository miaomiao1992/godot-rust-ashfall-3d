# ASHFALL · 余烬禁区 v0.3.1 LAN 合作修复版

分支：`feature/lan-coop`。四人局域网合作预发布版本。

## 关键修复：怪物身体不可见

修复单人和联机模式中，怪物有碰撞和雷达标记，却看不到身体、只显示头盔或配件的问题。

- 修正导入骨骼网格的渲染包围盒，使用与实际人物身高对应的范围。
- 关闭兼容渲染器下不稳定的网格压缩、自动 LOD 和阴影网格导入优化，并重新导入两套写实模型。
- 同步修正队友第三人称骨骼模型的包围盒。
- 新增实际画面对照检查，只比较骨骼身体，六类怪物在单人和 LAN 场景共 12 项渲染检查通过。
- 延长首次加载时的连接容忍时间，避免骨骼模型加载或着色器编译期间误判掉线；显式断线仍立即处理。

## 下载与开房

下载 `ASHFALL-LAN-Windows64-v0.3.1.zip`，完整解压后运行 `ASHFALL-LAN.exe`。
所有玩家均使用 v0.3.1；旧 LAN 版本会收到版本不匹配提示。

主菜单 → 局域网合作 → 填写昵称和房间名称 → 创建房间 → 房主开始尸潮。
队友通过房间列表或房主 IP 加入，可中途加入正在战斗的房间。
默认游戏 UDP 42042，发现 UDP 42043；同机测试使用 127.0.0.1，跨电脑使用局域网 IP。

## 合作内容

- 最多四人、三个独立空间关卡、九波尸潮与三个 Boss。
- 团队经验和武器等级共享，血量、弹药和强化独立，按 U 分配强化点。
- 20 秒倒地时间，队友按住 E 3 秒救援，超时观战、下一波复活。
- 全队覆灭后由房主重开；个人菜单不暂停战场，关闭友军伤害。
- Rust 实现房间发现、ENet 传输、类型化协议、压缩分包和合作规则。
