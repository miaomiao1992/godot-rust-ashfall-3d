# ASHFALL · 余烬禁区 v0.3.2 LAN — 独立幸存者角色

玩家与队友不再使用丧尸模型。现在是穿迷彩服、战术背心、头盔和军靴的独立幸存者士兵。

- 下载并接入 Grab3D CC0 士兵模型，使用独立人形骨骼及走／跑动画，并补充站立待机。
- 模型从 278,969 个三角形减至 27,896，贴图最大 2048px；保留材质、骨骼权重及动画。
- 移除旧丧尸身体上拼装的临时护甲／头盔。
- 增加真实画面、骨骼运动检查和幸存者／丧尸对照截图。
- 保留 v0.3.1 怪物显示和加载期间误掉线修复。

## 下载与游玩

下载 `ASHFALL-LAN-Windows64-v0.3.2.zip`，完整解压后运行 `ASHFALL-LAN.exe`。
所有联机成员统一使用 v0.3.2。主菜单 → 局域网合作 → 创建房间或加入房间，最多四人，支持热加入。
默认游戏 UDP 42042，房间发现 UDP 42043。包内附中文说明、资产来源及许可、SHA256 校验文件。
