# ASHFALL · 余烬禁区 v0.6.0 — CS_ASSAULT 仓库重构、真实海水、昼夜天空全局光照与 CS 物理手雷

Windows 10／11 x64，完整解压 `ASHFALL-LAN-Windows64-v0.6.0.zip` 后运行 `ASHFALL-LAN.exe`，无需安装 Godot 或 Rust。保留同目录 `.pck`、`.dll` 和许可文件。

## 新增与重点改进

### 1. CS_ASSAULT 经典突击仓库完整重构
- **高度还原经典场景**：按 CS 经典实景图全面重构 PvP 仓库地图，包含大卷帘门（正面突击大门）、3.2 米混凝土装卸作业大高台、中央大坡度水泥斜坡（连接车道与高台）、后墙四座红色进深货位槽与工业警示红光、二楼悬空钢架猫道与带发光绿屏的 CCTV 闭路监控室、天花板纵横三角钢桁架与长方形发光荧光吊灯箱、双排采光玻璃天窗、以及贯通屋顶与室内的经典通风管道系统（The Vent）。
- **真实 PBR 扫描贴图**：集成 Poly Haven CC0 真实工业扫描材质（沥青路面、拉毛混凝土、波纹钢板、集装箱铁皮、卷帘门、木箱），全场景采用三向投影（Triplanar Mapping），杜绝贴图拉伸变形。

### 2. 第 2 关真实物理海水模拟
- **物理摆线波（Gerstner Wave）**：180×180 细分高精物理曲面，4 组多向物理摆线波精确模拟真实波浪重力频散动力学，形成尖锐陡峭波峰与平缓宽阔波谷。
- **PBR 光学模型与次表面散射（SSS）**：真实 Schlick 菲涅尔反射（平视天光倒影、俯视墨碧通透）；深海 Beer-Lambert 吸收与波峰背光翡翠青绿次表面散射。
- **浪尖白冠沫与接触碎浪**：基于波陡 Jacobian 压缩比的浪尖白冠破浪泡沫，以及码头水泥立柱与货轮船体碰撞碎浪。

### 3. PvP 昼夜交替、日月天体与天空全局光照
- **24 小时连续天体轨迹**：白天太阳自东方升起至天顶并转为金红黄昏夕阳，夜间冷银月亮升起；DirectionalLight3D 实时追踪天体朝向、光照能量与色温平滑过渡。
- **场景阴影深度处理**：4 级 PSSM 级联阴影，180m 超大投射覆盖，精心调校偏置杜绝自阴影杂斑；阳光与月光穿透屋顶采光天窗，在室内地面与斜坡投射出移动钢架构剪影。
- **基于物理的天空全局光照（Sky GI）**：ProceduralSky 大气散射动态调节，环境光采用 `AMBIENT_SOURCE_SKY` 半球漫射填充暗部，保证战术可视性；镜面反射天空球。

### 4. CS 风格物理手雷系统
- **先切入手中，再投掷**：按 4 或 G（Q 闪光 / C 烟雾）收起枪械并将手雷切入双手，第一人称显示真实 3D 手雷模型（军绿弹体、螺纹引信颈、保险柄与拉环）；按 1/2/3/5/6 随时切回枪械取消投掷。
- **朝鼠标方向投掷**：鼠标左键全力高抛，鼠标右键低手轻掷/滚地雷；投掷速度继承角色奔跑惯性。
- **真实抛物线、反弹与贴地滚动**：物理重力加速度与飞行自转翻滚，碰撞墙面/地面时根据法线反弹并发出金属磕碰清脆响声；垂直动能衰减后**贴地平滑滚动**，带有摩擦减速与旋转，2.2 秒引信到期引爆。
- **强力物理冲击波**：周围物理道具（木箱、油桶）被向上大幅掀飞腾空翻滚；爆炸范围内的敌人与角色受到强力物理击退推力与强烈震颤，伴随瞬态白光爆闪、燃烧火花重力飞溅与浓黑升腾烟柱。
