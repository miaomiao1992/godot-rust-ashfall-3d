# ASHFALL · 余烬禁区 v1.0.0 — CS 1.6 Assault 场景与战斗细节

Windows 10／11 x64，完整解压 `ASHFALL-LAN-Windows64-v1.0.0.zip` 后运行 `ASHFALL-LAN.exe`。保留同目录 PCK、DLL 和许可文件。

## 场景与通行
- 基于原版 GoldSrc v30 `cs_assault.bsp` 转换实际几何、UV、182 张贴图与原始光照，恢复外部街区、高架公路、集装箱、仓库高台、斜坡、上层房间和屋顶。
- CT 室外出生、T 室内出生；保留团队 PvP，不生成任何人质，也没有救援任务。
- 原版狭窄方形通风管可进入。Ctrl 蹲伏，低顶下禁止站起；屋顶入口、上下层分支和可射开的格栅出口有实际碰撞验证。
- 八处原版梯子，靠近后 W／S 上下攀爬；门靠近自动开启。
- 三维导航网格与梯子、门连接替换旧的对称屋顶坡道导航。
- 室外连续昼夜变化：可见太阳、月亮与夜间星空；室内保留原版灯光分布。

## 战斗细节
- 手雷按住准备、松开出手；拉环最少 0.5 秒。参考 1.6 的视角相关抛速、角色惯性和 1.5 秒引信。右键轻掷作为扩展操作保留。
- 高爆雷半径 9 米，伤害随距离和障碍衰减；闪光按视线与朝向计算，烟雾不扣血。
- 烟雾减速落定后出烟，持续 25 秒，逐渐扩散、末尾淡出，替换旧的单个实心球。
- 狙击镜右键点击锁定，再次点击退出；镜内滚轮切换 4×／8×，切枪、换弹和死亡解除锁定。
- 墙体、木箱与金属管道按原版贴图材质分类，命中声音与痕迹对应混凝土、木材、金属。
- 死亡时立即隐藏浮空队伍圆盘及姓名标记，重生恢复。

## 界面
- 主菜单四个按钮采用等尺寸的 2×2 排列。
- 创建／加入房间、开始仓库交锋等按钮统一深色悬停与柔和边框。
- 起始地图标题与下拉框提高文字可读性，包括客户端只读状态。
- README 预览重新使用真实场景截图，替换旧的空天空图片。

## 联机
网络标识 `1.0.0-lan`，所有玩家使用 v1.0.0。游戏 UDP 42042，发现 UDP 42043。支持 1v1–5v5、可选机器人、热加入、死亡后 5 秒重生。

原版地图及贴图的作者、来源记录在 `THIRD_PARTY_ASSETS.md`；转换程序为 `tools/convert_assault.py`。
