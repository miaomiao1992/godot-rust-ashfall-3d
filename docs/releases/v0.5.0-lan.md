# ASHFALL · 余烬禁区 v0.5.0 — 仓库交锋

Windows 10／11 x64，完整解压 `ASHFALL-LAN-Windows64-v0.5.0.zip` 后运行 `ASHFALL-LAN.exe`，无需安装 Godot 或 Rust。保留同目录 `.pck`、`.dll` 和许可文件。

## 仓库 PvP 与可选机器人

- 新增「仓库 PvP」入口，支持 1v1 至 5v5 红蓝队竞技；50 杀或 10 分钟结算，5 秒重生，无友伤。
- 大厅增加房主控制的「缺位补机器人」勾选项，默认开启：单人直接开始 1v1，人数不平衡时补齐较少的一方。取消勾选后需要双方真人人数相等。
- 真人热加入替换机器人，离开时按需补回。机器人使用 A* 网格寻路、视线判断和真实角色碰撞移动，共用真人的弹药、射速、伤害与重生规则。
- 对称仓库包含三条主路线、四条可进入的空心工业管道、双方屋顶坡道，以及 11 米高屋顶交战区和实体掩体。

## 狙击与穿透

- 新增第六把武器 **SR-96 远望**：独立 5 发弹匣、射后拉栓、4×／8×真实聚焦瞄准镜和屏息。生存模式等级 8 解锁，PvP 直接可用。
- `6` 装备狙击枪，按住右键开镜，镜内滚轮切换倍率，站定按住 Shift 屏息。
- 按实体入口和出口测量厚度，结合枪械和材质判定子弹穿透；步枪、狙击枪、电磁炮有不同穿透上限，伤害随穿透厚度和层数衰减。
- 手雷冲击波可通过薄障碍造成衰减伤害，厚重承重墙阻断伤害，多层掩体累计衰减；闪光仍需要无遮挡视线。

## 场景物理与战斗痕迹

- 木箱、桶、交通锥能被角色推动、子弹冲击和爆炸击飞；箱／桶破坏后生成真实刚体碎片。
- 金属、木材、混凝土有不同的弹孔与命中反馈，穿透留下入口和出口痕迹，移动物体上的弹孔跟随物体。
- 爆炸闪光、烟尘、焦痕、碎片和近距离镜头震动；破桶留下化学污染残留。
- 场景物件和表面痕迹由房主同步到客户端与热加入玩家；限额为 192 处表面痕迹、48 个临时刚体碎片。
- 比赛计时、重生和投掷物引信按真实经过时间更新，避免低帧率下计时变慢。

## 联机与操作

- 同一局域网使用同一 **v0.5.0** 发行包。游戏端口 UDP 42042，房间发现端口 UDP 42043；支持房间发现和 IP 直连。
- `G` 手雷、`Q` 闪光弹、`C` 烟雾弹、按住 `Tab` 查看比分；`1–6`／滚轮切换武器。
- 保留原有三关生存和四人合作模式。

## 验证范围

- 28 项 Rust 测试及严格 Clippy；89 项生存模式集成检查。
- 30 项实体穿透、物理残留与狙击视觉检查，镜内目标实际渲染宽度验证 4×／8×聚焦倍率。
- 22 项真实角色管道／屋顶通行检查，14 项机器人设置、行为、补位与替换检查。
- 实际房主与客户端进程验证机器人热替换、狙击穿墙伤害、弹孔、污染、碎片和客户端权威复制；十人 PvP 验证比分、重生、投掷物、结算与重开。
- Windows x64 DLL／EXE 的 PE 检查、导出 PCK 的脚本／资源检查及 ZIP CRC／SHA-256 校验。联机运行验证在本机 macOS 完成，跨电脑 Windows 实机验证仍待完成。
