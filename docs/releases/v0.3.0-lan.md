# ASHFALL · 余烬禁区 v0.3.0 LAN 合作版

独立开发分支：`feature/lan-coop`。这是局域网合作功能的首个预发布版本。

## Windows64 游玩

下载 `ASHFALL-LAN-Windows64-v0.3.0.zip`，完整解压后运行 `ASHFALL-LAN.exe`。
无需安装 Godot 或 Rust。Windows 10/11 64 位，显卡支持 OpenGL 3.3。

## 创建与加入房间

- 主菜单选择「局域网合作」，填写昵称和房间名称后创建房间。
- 房主点击「开始尸潮」；同一局域网最多四人共同战斗。
- 房间列表自动发现等待中和正在战斗的房间，支持中途加入。
- 也可输入房主 IP 直接连接。`127.0.0.1` 用于同机多开，跨电脑使用大厅显示的局域网 IP。
- 默认游戏端口 UDP **42042**，发现端口 UDP **42043**。
- 满员、连接失败和房间关闭会显示提示；房主离开后客户端返回主菜单。

## 合作玩法

- 三个空间独立的关卡、九波尸潮与三个关底 Boss。
- 共享经验、等级与武器解锁；各玩家血量、弹药、强化独立。
- 按 **U** 分配个人强化，个人菜单不暂停队友的战斗。
- 倒地后有 20 秒救援时间，队友靠近按住 **E** 3 秒救援，恢复 30% 生命。
- 超时观战，下一波复活；全队失去战斗能力时结算，房主可重新开始。
- 中途加入继承队伍武器等级与强化点，并有加载期间的保护。
- 关闭友军伤害，尸潮强度随队伍人数增加。

## Rust 核心

Rust 实现 UDP 发现、ENet 传输、类型化消息、连接状态、压缩、MTU 分包与限量重组。
独立角色状态、射速、弹药、换弹、移动耐力、个人强化、倒地和救援由 Rust 核心管理。
Godot 负责物理场景、命中射线、界面与表现；场景适配器应用房主权威快照。
