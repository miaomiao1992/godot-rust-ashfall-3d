# ASHFALL · 余烬禁区 v0.3.4 LAN — 选图与战斗表现修复

## 新增与修复

- **房主选地图**：创建房间后在大厅选择起始地图，默认「断桥高架」，也可选择「沉没船坞」「熔心实验场」。队友同步所选地图；重新挑战保留本房间选图，新房间恢复默认。
- **队友射击表现**：显示五种武器、持枪姿态、瞄准俯仰、后坐力、枪口闪光和弹壳。客户端本机立即显示预测弹道，伤害与命中仍由房主确认；低帧率下新射击反馈至少显示一帧。
- **短曳光**：普通武器改成最长 1.2 米的快速移动曳光，避免贯穿整个场景的长射线。电磁炮和 Boss 冲锋预警保留光束，射程与伤害判定不变。
- **地面闪烁**：桥墩顶面移到桥板下，移除交叉平台的同高度重叠面，修复矩形亮块和跳动亮线；调整水道与金属地面的粗糙度。
- **尸体落地**：死亡后落到真实地面，最终姿态按变形网格底部贴地，适配高架、高低码头、实验场与坡道；血迹沿地面高度和法线铺放。
- **性能优化**：减少房主状态序列化和尸群目标数组重复分配，复用弹道网格、限制碎屑开销，使用显存压缩纹理。F3 新增 CPU／物理耗时、绘制调用及特效数量。

## 下载与游玩

下载 **`ASHFALL-LAN-Windows64-v0.3.4.zip`**，完整解压后运行 **`ASHFALL-LAN.exe`**。
所有联机成员使用同一版本。主菜单 → 局域网合作 → 创建或加入房间，最多四人，支持热加入。
房主在大厅选择起始地图，然后开始尸潮；从所选地图的第一波开始，之后继续后续关卡。

默认游戏端口 UDP **42042**，房间发现端口 UDP **42043**。
ZIP 附中文游玩说明、资产来源与许可；独立 `.sha256` 文件用于校验下载。
