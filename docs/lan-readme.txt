ASHFALL · 余烬禁区 LAN v0.3.4 / Windows 64 位
开发分支：feature/lan-coop

尸体落到真实地面，并按死亡姿态贴地；高架和坡道血迹高度同步修正。

F3 显示 FPS、CPU/物理耗时、绘制调用和特效数量，便于定位实机卡顿。

v0.3.2 玩家和队友采用独立幸存者士兵模型，迷彩服、战术背心、头盔、军靴。
包含待机、走路、跑步骨骼动画，不再使用丧尸身体作为队友外观。

本版修复单人和联机中丧尸身体消失、只显示头盔或配件的问题。
修正骨骼模型渲染包围盒，关闭不兼容的网格压缩、自动 LOD 和阴影网格优化。
六类怪物在单人及 LAN 场景的实际身体渲染对照测试均通过。

完整解压后双击 ASHFALL-LAN.exe，无需安装 Godot 或 Rust。
同一局域网的所有玩家使用本版完整文件夹。

开房：
主菜单 → 局域网合作 → 填昵称和房间名称 → 创建房间。
房主可在「起始地图」选择断桥高架、沉没船坞或熔心实验场，然后点击「开始尸潮」。
默认第一张地图；本房间重新挑战保留选图。最多四人：房主一人，队友三人。
大厅显示房主本机 IP。默认游戏端口 UDP 42042。

加入：
其他电脑打开局域网合作，房间列表自动刷新，选中房间后加入。
可以加入已经开始战斗的房间，自动同步关卡、怪物、队友和等级。
也可输入房主 IP 直接加入。127.0.0.1 仅用于同一台电脑多开测试。
房间发现端口 UDP 42043。无法发现时，可检查是否在同一局域网，并使用 IP 直连。
Windows 防火墙询问时允许游戏在「专用网络」通信。
满员、版本不匹配和连接断开会在界面提示。
房主离开后，客户端回到主菜单。

合作规则：
队伍共享经验、等级和武器解锁；血量、弹药和强化各自独立。
升级获得个人强化点，按 U 选择强化；选择和 Esc 菜单不会暂停其他玩家。
友军伤害关闭。尸潮数量与耐久随队伍人数增加。
倒地后有 20 秒救援时间；队友靠近按住 E 约 3 秒，恢复 30% 生命。
超时后观战，下一波复活。全队失去战斗能力时结算，房主可以重新开始。
中途加入时有场景加载保护，继承队伍武器等级，并获得相应强化点。

操作：
WASD 移动、鼠标转向、左键射击、右键瞄准、Shift 冲刺、空格跳跃。
R 换弹，F 手电，1–5/滚轮切换武器，U 个人强化，Esc 个人菜单。
E 操作实验场冷却阀；按住 E 救援倒地队友。

三关：断桥高架 → 沉没船坞 → 熔心实验场。
每关三波，第九波肃清后通关。实验场每波累计关闭 1/2/3 个冷却阀。
腐蚀落点固定，琥珀色预警后变绿才有伤害；头部与 Boss 胸腔为弱点。

技术与验证：
Rust 实现 UDP 房间发现、ENet 传输、压缩分包、角色状态与合作规则。
Godot 负责物理场景、人物表现、HUD 和引擎接口桥接。
已进行本机多进程房主+三客户端、热加入、满员拒绝、救援和跨关验证。
跨电脑 Windows 专用网络仍需实机确认。资产许可见 THIRD_PARTY_ASSETS.md。
