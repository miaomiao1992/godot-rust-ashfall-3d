v0.5.0 仓库交锋 PvP、聚焦狙击和战斗物理：
主菜单 → 仓库 PvP → 填昵称和房间名 → 创建房间。
支持 1v1 至 5v5。房主可勾选「缺位补机器人」：默认勾选，单人即可开始与对面机器人对战。
多人时补齐较少的一方；真人加入会替换机器人，离开后按需补回。取消勾选时双方真人人数需相等。
机器人使用网格寻路、真实角色碰撞、视线判断、追击、侧移、射击和换弹；共用真人战斗和重生规则。
先取得 50 杀获胜，10 分钟到时按比分结算；阵亡后 5 秒重生，出生保护 2 秒，无友伤。
仓库包含中央货仓、装卸／维修通道、四条可双向穿行的空心管道，以及两侧坡道连接的 11 米屋顶。
PvP 中六种武器全部解锁。6 装备 SR-96 狙击枪，按住右键开镜，镜内滚轮切换 4×／8×，站定按住 Shift 屏息。
狙击镜使用真实摄像机聚焦，射后拉栓，独立 5 发弹匣；生存模式在等级 8 解锁。
G 手雷、Q 闪光弹、C 烟雾弹，每次出生携带 2／2／1 枚；按住鼠标准备并保持持雷瞄准，松开左键才高抛，松开右键才轻掷。切枪取消准备，按住期间不会提前投掷；按住 Tab 看比分。
木箱、桶和交通锥可被推动和击飞，箱／桶可被打碎，产生真实物理碎片；弹孔、爆炸焦痕、烟尘和破桶污染有持续残留。
子弹按枪械、材质和实际穿过的厚度判定穿透，入口／出口都有痕迹，穿透后伤害衰减。
步枪／狙击枪／电磁炮的混凝土穿透上限分别为 0.25／0.55／1.00 米，金属为 0.10／0.30／0.50 米。
手雷冲击波可通过薄障碍，厚重墙体阻断伤害，多层障碍累计衰减；闪光需要无遮挡视线。
痕迹、物件、弹药、机器人、比分、重生与重开均由房主同步；低帧率下比赛、重生和引信使用真实经过时间。
联机玩家统一使用 v0.5.0 完整文件夹；网络标识为 0.5.0-lan。

完整解压后双击 ASHFALL-LAN.exe，无需安装 Godot 或 Rust。
同一局域网的所有玩家使用本版完整文件夹。

开房：
主菜单 → 局域网合作 → 填昵称和房间名称 → 创建房间。
房主可在「起始地图」选择断桥高架、沉没船坞或熔心实验场，然后点击「开始尸潮」。
默认第一张地图；本房间重新挑战保留选图。最多四人：房主一人，队友三人。
大厅显示房主本机 IP。默认游戏端口 UDP 42042。

加入：
其他电脑打开局域网合作，房间列表自动刷新，选中房间后加入。
可以加入已经开始战斗的房间，自动同步关卡、怪物、队友和等级。
也可输入房主 IP 直接加入。127.0.0.1 仅用于同一台电脑多开测试。
房间发现端口 UDP 42043。无法发现时，可检查是否在同一局域网，并使用 IP 直连。
Windows 防火墙询问时允许游戏在「专用网络」通信。
满员、版本不匹配和连接断开会在界面提示。
房主离开后，客户端回到主菜单。

合作规则：
队伍共享经验、等级和武器解锁；血量、弹药和强化各自独立。
升级获得个人强化点，按 U 选择强化；选择和 Esc 菜单不会暂停其他玩家。
友军伤害关闭。尸潮数量与耐久随队伍人数增加。
倒地后有 20 秒救援时间；队友靠近按住 E 约 3 秒，恢复 30% 生命。
超时后观战，下一波复活。全队失去战斗能力时结算，房主可以重新开始。
中途加入时有场景加载保护，继承队伍武器等级，并获得相应强化点。

操作：
WASD 移动、鼠标转向、左键射击、右键瞄准、Shift 冲刺、空格跳跃。
R 换弹，F 手电，1–6/滚轮切换武器，U 个人强化，Esc 个人菜单。
E 操作实验场冷却阀；按住 E 救援倒地队友。

三关：断桥高架 → 沉没船坞 → 熔心实验场。
每关三波，第九波肃清后通关。实验场每波累计关闭 1/2/3 个冷却阀。
腐蚀落点固定，琥珀色预警后变绿才有伤害；头部与 Boss 胸腔为弱点。

Godot 负责物理场景、人物表现、HUD 和引擎接口桥接。
已进行本机多进程房主+三客户端、热加入、满员拒绝、救援和跨关验证。
