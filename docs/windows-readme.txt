ASHFALL · 余烬禁区 v0.2.1 空间重制修复版 / Windows 64 位

本版修复第三关怪物被击退出地板后，仍占据存活计数导致无法进第二波的问题。
气闸后方有实体封挡；意外跌落怪物保留血量回到有效地面。
出生失败会重试，存活数量与实际场景同步。

启动：完整解压压缩包，双击 ASHFALL.exe，点击「进入禁区」。
无需安装 Godot 或 Rust。保留同文件夹中的 PCK、DLL 与所有随包文件。
系统：Windows 10 / 11 64 位，支持 OpenGL 3.3 的显卡，键盘与鼠标。

操作：
WASD 移动，鼠标转向
鼠标左键射击、右键精确瞄准
Shift 冲刺（消耗耐力），空格跳跃
R 换弹，F 手电
E 操作实验场冷却阀
1–5 或滚轮切换已解锁武器
Esc 暂停，可调整鼠标灵敏度
F3 查看性能信息

挑战：
断桥高架 → 沉没船坞 → 熔心实验场
高架：悬空折线公路、4m 到 8m 上坡、断裂的上下立交。
船坞：海水隔开的四条码头，横桥换线，东码头装卸坡道。
实验场：中央实体核心、环形大厅、四向气闸，关闭三个冷却阀。
每关三波尸潮，第三波出现 Boss。
成长与武器跨关保留，第九波肃清后通关。
实验场每波还需累计关闭 1/2/3 个阀门。靠近控制台按 E。
未关闭阀门会在雷达标记；三阀全部关闭后 Boss 护罩解除。
死亡可重新挑战；最佳纪录自动保存。

武器解锁：
LV.1 守夜者手枪（备用弹药无限，仍需换弹）
LV.2 疾风冲锋枪
LV.3 破门者霰弹枪
LV.5 灰烬突击步枪
LV.7 审判电磁炮（可穿透尸群）

生存提示：
爆头和 Boss 胸腔核心命中有额外伤害与成长奖励。
升级时选择伤害、生命抗性或机动换弹强化。
不要停在尸群中；雷达提示侧后方威胁。
回收急救包与弹药。每波间歇会恢复部分生命与弹药。
Boss 冲锋需横向闪避，砸地圈可离开或跳跃。
腐蚀是固定落点：琥珀色倒计时预警至少 1.6 秒，绿色出现才有伤害。
船坞 Boss 三连线与环形轮换；实验场 Boss 固定十字图案，向对角闪避。
落点预警后不会再追踪你。腐蚀区短时间后消退，同屏最多六处。
击杀腐蚀者可以打断未爆发的预警。
Boss 半血后狂暴，技能频率上升。
